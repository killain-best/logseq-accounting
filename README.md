# 日志记账（logseq-accounting）

在 Logseq **日志页**里嵌入式记账的本地插件：斜杠命令快速录入，账单以 **DB 属性**形式挂在块上，自带统计仪表盘和预算管理。

> ⚠️ 仅支持 **DB 版 graph**（数据库版）。文件版（Markdown/Org）graph 无法使用，插件启动时会检测并提示。

## 功能

- **`/记账-支出`、`/记账-收入`**：弹出表单（金额*、分类、账户、备注），确认后自动在当前位置写入结构化账单块
- **`/记账报表` 或工具栏 💰 按钮**：打开仪表盘
  - 概览：本月支出/收入/结余、分类支出环形图、近 6 个月收支柱状图
  - 明细：按日分组，点击任意一条跳回日志原块
  - 预算：按分类设月度预算，进度条显示，超支变红
- **记账块卡片化**：日志里的账单块自动渲染为卡片样式（蓝边 + 圆角底色）
- **实时刷新**：开着仪表盘记账/改属性，数据自动更新
- 暗色/亮色主题自适应

## 安装与加载

```bash
npm install
npm run build
```

然后在 Logseq 桌面端：

1. `设置 → 高级 → 开发者模式` 打开
2. 工具栏右侧 `···` 菜单 → `插件`（或 `t p`）进入插件页
3. 点击 `Load unpacked plugin`，选择本项目根目录（`D:\01_APPS\logseq-accounting`）
4. 插件启用后即可使用

修改代码后：重新 `npm run build`，在插件页点该插件的 **重载（reload）** 按钮。

## 数据模型（重要）

- 每笔账是一个带 `#账单` 标签的块，**块标题 = 备注**（自动带 💸/💰 前缀）
- 4 个 DB 属性（显示名 → key）：
  | 显示名 | key | 类型 |
  |---|---|---|
  | 金额 | `txn_amount` | number |
  | 类型 | `txn_type` | default（`支出`/`收入`） |
  | 分类 | `txn_category` | node（引用页面，可点进去反查） |
  | 账户 | `txn_account` | node |
- **日期 = 块所在日志页的日期**，不单独存日期属性。补记请到对应日期的日志页录入
- 非日志页上的账单块不纳入统计
- 所有数据都在 graph 里：删块 = 删账；属性面板可直接改金额/分类，统计自动跟随
- 分类/账户是 node 型属性，首次使用新值会自动创建同名页面（如「餐饮」页），这是 DB 版的正常特性

## 设置（插件设置页）

| 项 | 默认 |
|---|---|
| 币种符号 | ¥ |
| 支出分类 | 餐饮,交通,购物,居住,娱乐,医疗,教育,其他 |
| 收入分类 | 工资,奖金,理财,兼职,其他 |
| 账户 | 现金,微信,支付宝,银行卡 |
| 分类月预算 | 建议在仪表盘「预算」页可视化编辑 |

## 卸载与清理

在插件页卸载即可。插件只**新增**过 `#账单` 标签和 4 个属性定义，不会改动你的任何已有数据；已记录的账单块是纯数据，卸载插件后依然保留、可正常查询。

## 技术栈

TypeScript + React 18 + Vite，图表为手写 SVG（零依赖）。Logseq Plugin SDK：`@logseq/libs`（DB 属性 API + Datascript 查询）。
